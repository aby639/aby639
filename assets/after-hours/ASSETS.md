# After-hours profile assets

The welcome scene was generated for Aby Daniel Varghese with OpenAI's image-generation tool. The typography, chapter illustrations and rain/cursor animation were created for this profile. Desktop and mobile compositions are separate; each has a still-image fallback.

The profile's MemoLens preview uses an app screenshot with sample entries. Its editable layout is in `tools/memolens-preview.html`. The linked demo is available at https://www.youtube.com/watch?v=bV9s-qFNM9c. Earlier GIF excerpts remain in the assets folder but are no longer displayed.

The welcome banner's editable text and animation are in `tools/welcome.html`, using `welcome-background.png` as the artwork. Desktop and mobile GIFs retain the rain and cursor animation; the still images use the same text.

The Naruto and Sasuke GIF is an excerpt from the anime clip Aby supplied for his profile. It is fan material, not original artwork by Aby; rights remain with the respective creators and rights holders.

The contribution still comes from this repository's actual contribution-snake output. The animated SVG remains connected to the existing output branch.

The visual references were https://github.com/trinib, https://github.com/Ahtisham-1214 and https://github.com/Sia-WRWD. Their artwork and README implementation were not copied.
