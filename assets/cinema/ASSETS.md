# Cinema profile assets

The editable banner and MemoLens layout are in `tools/cinema.html`. They render separate desktop and mobile compositions. `hero.gif` and `hero-mobile.gif` use the same 2.8-second Demon Slayer sequence; the PNG versions are reduced-motion fallbacks.

The Demon Slayer sequence is a fan-shared excerpt on [Tenor, posted by Faisal1435](https://tenor.com/view/demon-slayer-kimetsu-no-yaiba-kimetsu-demon-slayer-gif-802320408899345404). Its MP4 media URL is https://media.tenor.com/CyJqKTh92_wAAAPo/demon-slayer-kimetsu-no-yaiba.mp4. The footage is not original artwork by Aby. Demon Slayer belongs to its respective creators and rights holders. The source MP4 is retained so the layout can be rendered again.

The Naruto GIF remains the exact supplied file in `assets/after-hours`, including its static fallback. The contribution snake still points to the existing output branch, with its existing workflow unchanged.

The MemoLens panels use the existing app screenshot with sample entries. The SVG headings and contact panel contain editable text and vector shapes. Previous profile assets remain available but are no longer displayed by the new README.
