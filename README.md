### MemoLens

**MemoLens** lets you save photos with captions, moods, tags and optional voice notes. It stores entries on your device, with favourites and search by caption, mood or tag.

<a href="https://www.youtube.com/watch?v=bV9s-qFNM9c">
  <img src="./assets/after-hours/memolens-film-preview-static.png" width="100%" alt="MemoLens photo journal with sample entries. Click to watch the demo." />
</a>

**[▶ Watch the demo](https://www.youtube.com/watch?v=bV9s-qFNM9c)** &nbsp; · &nbsp; [Source code](https://github.com/aby639/my-gallery) &nbsp; · &nbsp; [Project details](https://aby-portfolio-gules.vercel.app/work/memolens)

**React Native · Expo · TypeScript · AsyncStorage**<br />
This is a personal project in testing. Voice recording runs on Android and iOS; the demo shows the web version with sample entries.
